# Configuration

Most people never need this: everything below can be changed in **Settings** (⌘, in the launcher).
Settings reads and writes the same file.

## config.json

`~/.config/lodestar/config.json` — every key is optional:

```json
{
  "hotkey": "cmd+shift+space",
  "appDirectories": ["~/Dev/Apps"],
  "clipboardHistoryLimit": 300,
  "clipboardHistoryEnabled": true,
  "appearance": "dark",
  "launcherPosition": "center",
  "showMenuBarIcon": true,
  "emojiSkinTone": "medium",
  "commands": {
    "cmd:files": { "enabled": false },
    "cmd:clipboard": { "alias": "cb" },
    "sys:lock": { "hotkey": "ctrl+option+l" }
  }
}
```

| Key | Values |
| --- | --- |
| `hotkey` | The launcher shortcut, e.g. `cmd+shift+space`. Default ⌥Space. Must include ⌘, ⌥ or ⌃. |
| `appDirectories` | Extra folders to search for apps (on top of `/Applications`, `/System/Applications`, `~/Applications`). |
| `clipboardHistoryLimit` | How many entries to keep (default 300). Pinned entries are never pruned. |
| `clipboardHistoryEnabled` | `false` stops recording. |
| `appearance` | `system` (default), `light` or `dark`. |
| `launcherPosition` | `upperThird` (default) or `center`. |
| `showMenuBarIcon` | `false` hides the menu bar star. Open Settings with ⌘, in the launcher, or open Lodestar.app again to show the launcher. |
| `emojiSkinTone` | `light`, `mediumLight`, `medium`, `mediumDark` or `dark` (missing = default yellow). |
| `commands` | Per-command settings keyed by command ID (shown in Settings › Extensions): `enabled`, `alias`, `hotkey`. |

- Changes made in Settings apply immediately. Defaults are stored by leaving the key out.
- Settings rewrites only the keys it manages and leaves others alone. If the file isn't valid JSON,
  Settings shows an error instead of overwriting it.
- Hand edits are read at launch, so restart Lodestar after editing the file.
- **Reload Scripts and Extensions** (a command and a menu bar item) picks up new scripts and extensions live.

Update preferences (automatic checks, pre-releases, skipped version) are stored in the app's
preferences (`io.github.lodestar-launcher`), not in this file.

## Where Lodestar keeps things

| What | Where |
| --- | --- |
| Config | `~/.config/lodestar/config.json` |
| Script commands | `~/.config/lodestar/scripts/` |
| Extensions | `~/.config/lodestar/extensions/` |
| Usage ranking | `~/Library/Application Support/Lodestar/frecency.json` |
| Clipboard history | `~/Library/Application Support/Lodestar/clipboard.json` (0600) and `clipboard/` (0700, images and formatting) |
| Emoji favorites and recents | `~/Library/Application Support/Lodestar/emoji.json` |
| Color history | `~/Library/Application Support/Lodestar/colors.json` |

## Settings window

- **General:** launcher shortcut (click the field and press the new combo; Esc cancels, Delete restores
  ⌥Space; global shortcuts pause while recording), launch at login (bundled app only; uses
  `SMAppService`), appearance, launcher position, menu bar icon, and **Updates** (automatic checks,
  pre-releases, Check Now, last check).
- **Extensions:** every command in a searchable table with an on/off switch, alias and hotkey, plus a
  detail pane with its ID and file location.
- **Clipboard:** turn history on or off, set its size, clear it.
- **Advanced:** live permission status, file locations, reset the welcome screen or all command settings.
- **About:** version, license, Check for Updates.

Command hotkeys for commands that just do something (system commands) run without opening the
launcher; commands with a screen (Clipboard History, extensions) open it.

## Welcome screen

Shown on first launch. Reopen it with **Show Welcome…** in the menu bar, the **Show Welcome Screen**
command, Settings › Advanced, or by launching with `--onboarding`. Finishing it stores
`onboardingCompletedVersion` in the app's preferences.

## All keyboard shortcuts

| Key | Action |
| --- | --- |
| ↑ / ↓, ⌃P / ⌃N | Move the selection |
| ← / → | Move in a grid (emoji & symbols) |
| ⌫ on an empty search | Back to the previous screen |
| Return | Primary action |
| ⌘Return | Secondary action |
| ⌘K | Actions for the selected item |
| ⌘P | Type filter (Clipboard History) |
| ⇧⌘P, ⌃X, ⌃⇧X | Pin, delete, clear all (Clipboard History) |
| ⇧⌘O | Open With… (files) |
| ⌘, | Settings |
| ⌘1 … ⌘5 | Settings tabs |
| Esc | Close a popover, go back, clear the search, then hide |

## Emoji data

The emoji and symbol data (`Sources/LodestarCore/Resources/emoji.json`) is generated by
`scripts/generate-emoji-data.py` from Unicode 17.0 (`emoji-test.txt`, `UnicodeData.txt`) and the CLDR 48
English annotations. Unicode data © Unicode, Inc., used under the
[Unicode License v3](https://www.unicode.org/license.txt); see [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
Glyphs come from the system font; no emoji artwork is bundled.
