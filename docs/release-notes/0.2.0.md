## What's new in 0.2.0

- **Uninstall Application.** Press ⌘K on an app and choose **Uninstall Application** (⌃X) to remove it.
- **Clipboard history pastes where you were typing.** Pressing Return on a clipboard entry now always pastes into the app you were using before opening Lodestar.
- **Clearer permissions.** One shared permissions list with a summary and clearer next steps, refreshed live as you grant access, and the correct pane name on macOS 27.
- **Developer ID signing for local builds.** `scripts/bundle.sh` signs with your Developer ID automatically when you have one.
